Cette nouvelle version de l'application OnelittleAngel a eu pour objectif de créer une version commune à la fois pour Android et iOS, dans l'objectif de créer une charte graphique et une application identique pour les deux plateformes. L'application est disponible sur le PlayStore et l'AppStore et reprend la fonctionnalité de création de favoris, permet de sélectionner une thème de couleur et un mode d'affichage système, light ou dark. 

L'objectif a été avant tout de publier une version Minimum Valuable Product identique pour les deux plateformes pour incrémenter de nouvelles fonctionnalités lors de prochaines versions.

Compétences : Programmation orientée objet (POO) · Intégration continue et livraison continue (CI/CD) · Kotlin Multiplatform · SwiftUI · Base de données Realm · Agile Environment · CocoaPods · Swift (langage de programmation) · AppStore Connect · Développement Android · Figma (logiciel) · Gimp · Kotlin · Compose Multiplatform · SQLite · Google Play Console · Développement iOS · Google Material Design · Développement Android SDK | Kotlin | Java · Git · Gradle · SDK Android · Autonomie · Coroutines Kotlin
